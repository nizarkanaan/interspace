# Launchable Mac app Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Replace manual HTML opening with a native app and connected Orchestrator.
**Architecture:** AppKit/WKWebView -> enumerated JSON-lines pipe -> Python state/workflow -> Codex CLI; reuse the read-only snapshot runner.
**Tech Stack:** Swift AppKit/WebKit, Python standard library, native HTML/CSS/JS.
**Spec:** docs/superpowers/specs/2026-11-10-macos-app-design.md

## Global Constraints

- Stay on feature/readonly-pilot; do not merge main or touch Sample Project.
- Use committed allowlisted snapshot inputs and Codex-managed credentials.
- No listener/server, external writes, simulations, unbounded retries or sample provider fallback.

## Review Focus

- Malformed/unsupported model operations never dispatch.
- Two UI starts or stale plan versions cannot duplicate work.
- Provider cancellation/timeout kills children and never shows completed.
- Restarted app preserves threads and marks interrupted work.
- Bundled local UI cannot navigate to external privileged content.
